# Помидорный тир

Оформление в духе старых сайтов и Windows 95: объёмный заголовок, серые окна и кнопки. Фоны: улица, сцена, подвал и загрузка своего изображения. Фоновые фотографии предоставлены пользователем. Помидор и деревянная рогатка — фотореалистичные изображения с прозрачным фоном, созданные встроенным ImageGen. Все картинки находятся в assets/; внешние сервисы и шрифты не требуются.

Статическая игра для компьютера. Откройте index.html в браузере для локальной проверки. Сервер, сборка и установка библиотек не нужны. Загруженные изображения остаются в браузере и не отправляются на сервер. После перезагрузки фото, фон и результаты сбрасываются.

## Управление

Загрузите фотографию, выберите один из трёх фонов или свой файл. Наведите курсор, удерживайте левую кнопку и отпустите. Щелчок даёт минимальную силу, 0,5 секунды — слабую, 1 секунда — среднюю, 1,5 секунды — максимальную. Рогатка закреплена по центру. Помидоры летят по дуге в точку прицела; сила определяет скорость полёта. Попадание проверяется в момент прилёта, поэтому нужно учитывать движение фотографии. Пятна обрезаются по фотографии и движутся с ней. Есть пауза и очистка пятен. Мобильное управление не входит в эту версию.

## GitHub Pages

1. Создайте репозиторий GitHub с основной веткой main.
2. Добавьте в корень репозитория всё содержимое этой папки, включая скрытую папку .github. При загрузке через веб-интерфейс проверьте, что файл .github/workflows/pages.yml действительно появился; при необходимости создайте его через Add file → Create new file.
3. В Settings → Pages → Build and deployment выберите Source: GitHub Actions.
4. Во вкладке Actions откройте Publish GitHub Pages и запустите Run workflow. При последующих изменениях main публикация запускается автоматически.
5. После успешного выполнения ссылка появится в Settings → Pages и в результате задания deploy.

Можно обойтись без Actions: в Settings → Pages выберите Deploy from a branch, ветку main и папку /(root), затем Save.

Не загружайте сам ZIP в репозиторий: сначала распакуйте архив и перенесите файлы из папки tomato-game в корень репозитория.
